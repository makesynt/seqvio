# Product Hunt Copy

## Tagline

Open-source explainer videos for coding agents.

## Short description

Seqvio turns technical ideas and real terminal/browser evidence into
narration-locked explainer videos. Review the editorial plan, choose a visual
direction, compile an inspectable `ExplainerDocument`, align each spoken phrase
to a visual action, run QA, and render locally.

## Maker comment

Seqvio is for developers and technical educators who want video production to
live beside the code it explains. A host agent makes the creative decisions;
Seqvio makes them reviewable and executable. The same `ExplanationBeat` can
connect a narrated claim to a diagram, code highlight, or observed terminal and
browser state. Capture adapters are experimental and clearly labeled; the public
authoring and rendering path is deterministic and local.

## Demo promise

The first 75 seconds should show one real technical problem from start to finish:
the readable plan, the observed evidence, the formal IR, one phrase-level beat,
the QA result, and the final video. A style gallery can follow as supporting
material; it should not be the product's primary proof.
