# Product Hunt Copy

## Tagline

Open-source explainer videos for agents.

## Short description

Seqvio turns real agent work and authored ideas into narration-locked explainer
videos. Review the editorial plan, choose a visual
direction, compile an inspectable `ExplainerDocument`, align each spoken phrase
to a visual action, run QA, and render locally.

## Maker comment

Seqvio is for developers and technical educators who want video production to
live beside the code it explains. A host agent makes the creative decisions;
Seqvio makes them reviewable and executable. The same `ExplanationBeat` can
connect a narrated claim to a diagram, code highlight, or observed terminal and
browser state. Capture packages remain experimental; captured evidence shown in
the demo is real, while the public authoring and rendering path is deterministic
and local.

## Demo promise

The 64-second demo follows a real skill evaluation from an agent task to
terminal and browser evidence, reviewable editorial and visual direction,
phrase-anchored timing, deterministic QA, and a closing montage of six supported
explanation applications.
